# 科学ショートを1本つくる

対象は `public/shorts/`(scenes.js / app.js / style.css)。ユーザーは生態系・進化・脳・地球史など「つながりの全体像」が好きで、論文を最初から読む気はない。入口として「おっ、面白そう」と思える短い映像を作る。

## 手順(順番を飛ばさない)

### 1. テーマを決める
- ユーザーの興味に合うか(生物と地球のつながり、動物としての人間、進化、脳)。
- 「実験や観察で確かめられた事実」が1つあるか。1動画1主張。
- 動きで見せられるか(粒子、移動、成長、変形)。図解の紙芝居にならないか。
- 既存のショートと重複しないか(`SOURCES.md` を確認)。

### 2. 調べて、照合する(ここが最重要)
- WebSearch/WebFetch で原著論文を探し、**抄録か本文を開いて**主張・数字・年代・雑誌・巻号ページを確認する。記憶だけで書かない。
- 確認できなかった数字は動画に出さない。
- 議論がある話題は、反対の論文や批判も1本は探し、`caveat` に書く。
- 結果を `public/shorts/SOURCES.md` に行追加し、確認できたら状態を「確認済み」にする。

### 3. 設計する(コードを書く前に決める)
- **フック**: 2行、約10字ずつ。問いで終えて答えを伏せる(例: 木は地下で、会話しているのか？)。断定の見出しより「？」型が効く。
- **センターピン**: 「おお！」となる核心の1瞬間。時刻と、短いスタンプ文言(例: ぶつかった！)。
- **字幕**: 4〜5個、1行で読める長さ。時刻はシーン内の秒。
- 動画は約22〜28秒(再生は1.35倍速)。

### 4. 実装
`scenes.js` に `S.push({...})` を足し、末尾の `window.SCENES=[...]` の並びに入れる。
```js
S.push({
  id:'xxx', pin:{t:12,text:'ぶつかった！'}, hook:['1行目','2行目？'], tag:'分類', dur:24,
  title:'解説パネルの見出し',
  beats:[{t:0,text:'短い字幕<b>強調</b>'}, ...],
  more:'やさしい解説 2〜3文',
  caveat:'議論・限界・模式図であることの注意',
  source:{short:'著者 年, 雑誌', cite:'完全な引用', query:'論文タイトル(検索リンク用)'},
  init(W,H){ return {/* 乱数は rng(seed) で固定。状態はここに */} },
  draw(c,t,W,H,s){ /* 論理幅360、高さHは可変。t はシーン内の秒 */ }
});
```
- 描画領域は上から約 H×0.1〜0.6。下側は字幕と操作ボタンが載る。
- 画像ファイルは使わず canvas で描く。光る表現は `globalCompositeOperation='lighter'` と `glow()`。
- 外部通信なし、ビルド不要を保つ。

### 5. 目視で確認する
```
node tools/shorts/shoot.cjs <出力dir> <id> 1,6,12,13,20
```
撮れた画像を Read で見て、次を確認する: 文字の重なり・はみ出し、フック2行が折り返さないか、センターピンで何が起きるか分かるか、下側が空きすぎていないか、コンソールエラーなし。
直したら必ずもう一度撮る。

### 6. 公開
- `git add public/shorts && git commit` して、指定ブランチに push。
- Claudeアーティファクトにも出す場合: `python3 tools/shorts/bundle.py <出力>.html` で1枚にまとめ、Artifact で公開する。**既存のリンクを上書きせず、別ファイル名で新しいリンクにする**(ユーザーは旧版を残したがる)。
- 返答には、確認したこと/していないこと、論文の確認状況を正直に書く。

## 守ること
- 出典が「未確認」のショートは、そう伝えてから渡す。
- 議論がある話を断定しない。模式図は模式図と書く。
- ヒトへの当てはめ(特に恋愛・精神)は、動物実験の結果と分けて書く。
