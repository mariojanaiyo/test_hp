# 興味プロフィール

テーマ選び(`pick-themes`)が読む、ユーザーの好みの定義。ユーザーの反応が出るたびに「学習メモ」へ追記する。

## ユーザーの言葉(原文)
> 生物学とか脳科学、進化心理学、動物としての人間とかそれに付随して、動物とか生物とかどう関連するかとか、マメ科と哺乳類の関係とか。地球の変動と生物のでき方みたいな大きなながれ(マクロ)と人間のつながり。全般まあ科学系は好き。
> E.O.ウィルソンみたいな、世界や宇宙のつながり全体の話が好き。たとえば、熊を殺せば鹿が大量発生して森は死ぬ。ほかにも森への影響が大きすぎる。そういう自然の流れがすごい好き。
> それを感覚的、直感的に示しているのがチームラボ。最初から論文を読む気にはならないので、最初に「おっこれ面白そう」となるショート動画を自分のために作りたい。

## 軸(テーマがどれに当たるかで採点する)
| 記号 | 軸 | 例 |
|---|---|---|
| A | 連鎖・カスケード(1つを変えると全体が変わる) | 捕食者と森、キーストーン種 |
| B | 地球の変動 × 生物の成り立ち(マクロ) | 大陸移動、酸素、気候変動と進化 |
| C | 動物としての人間(進化心理・行動) | 笑い、配偶、利他、社会脳 |
| D | 脳・神経 | 腸脳相関、社会脳、報酬系 |
| E | 生物どうしの関係(共生・寄生・マメ科と哺乳類) | 根粒菌、腸内細菌、寄生虫 |
| F | E.O.ウィルソン系(社会生物学、超個体、島の生物地理学、バイオフィリア) | アリ、島の種数、自然を好む本能 |
| G | 見た目で直感的に分かる(チームラボ的。動き・光・ネットワーク) | 菌糸網、粒子の流れ |

## 採点(合計 0〜21点、候補ごとに付ける)
- 軸の適合: 当てはまる軸ごとに 0〜3(最大3軸まで数える)
- 映像向き: 1〜3(動き・変化・つながりで見せられるか。図解だけなら1)
- 事実の確かさ: 1〜3(再現された結果か。議論中なら1)
- センターピン: 1〜3(「おお！」となる核心の一瞬があるか)
- 新規性: 1〜3(既存ショートと軸・スケール・生物が被らないほど高い)
- 条件: **軸の適合が2軸以上で2点以上**、かつ事実の確かさが1点(議論中)の場合は `caveat` で扱えること。満たさない候補は落とす。

## 並べ方の決まり
- 連続して同じ軸・同じ生き物にしない。
- ミクロ(細胞・遺伝子)とマクロ(地球・生態系)を交互に混ぜる。
- 最初の数本は、A・B・F(ユーザーの原体験に近い話)を優先する。

## 学習メモ(反応の記録。ここを根拠にフックと採点を調整する)
- 「木は地下で、会話しているのか？」のフックが最高と好評 → フックは**問いで終え、答えを伏せる**。「見えないところでつながっている」話は強い。
- 「ぶつかった場所で進化や交配が起きる」に興奮 → **境界・衝突・接触で何かが生まれる**話(交雑、大陸衝突、生態系の混ざり合い)を加点。
- 「考えながら見るのではなく、流し見で面白い」 → 説明より**一発の絵**で伝わる話を優先。
- 例に挙げた「熊を殺せば鹿が増えて森が死ぬ」は、そのままテーマ化する(BACKLOG 1位)。
